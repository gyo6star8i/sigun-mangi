# 시군만기 판정기

경상북도교육청 초등 교사(교감)의 **시·군 근무상한기간 만기 여부**를 판정하는 웹 도구입니다.
나이스 인사기록 > 경력 화면에서 내려받은 엑셀 파일을 올리면, 현임 시·군 전입일부터 산정 기준일까지의 기간에서 휴직·파견·직위해제·정직 기간을 빼고 실근무기간을 계산해 만기 대상인지 알려줍니다.

**사용하기:** https://gyo6star8i.github.io/sigun-mangi/

## 근거
- 2026학년도 교육공무원(초등) 인사관리기준 제13조①(구역별 근속근무상한기간), 제14조①(동일교), 별표1 2-나-1)
- 2026학년도 인사관리실무요령(초등) Ⅱ-1-가-2)(내신 기준일), Ⅱ-1-가-5)-라)(휴직·파견 등 제외 후 전후 통산)

| 구역 | 시·군 | 교사 | 교감 |
|---|---|---|---|
| 1 | 경산, 칠곡 | 8년 | 6년 |
| 2 | 구미, 영천, 청도, 고령, 성주 | 10년 | 6년 |
| 3 | 포항, 경주, 김천, 안동, 영주, 상주, 문경 | 15년 | 6년 |
| 4 | 의성, 청송, 영양, 영덕, 예천, 봉화, 울진 | 20년 | 7년 |
| 4 | 울릉 | 3년 | 3년 |

## 개인정보
파일은 브라우저 안에서만 읽고 서버로 전송하지 않습니다. 이 저장소에는 실제 교원 자료가 들어 있지 않습니다(화면의 예시는 가상 자료).

## 유의
판정 결과는 참고용입니다. 전보유예(제20조), 도서벽지 특례, 초빙교사, 영양교사의 교육청 근무 기간 등은 화면의 '제외 기간 추가'와 '보정'으로 직접 반영해야 하며, 최종 판단은 인사 담당자가 나이스 발령일자로 확인해 주세요.
